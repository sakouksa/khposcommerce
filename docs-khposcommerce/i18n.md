# 🌐 Internationalization (i18n) 5-Language System

## 1. Supported Locales & Coverage

The platform natively supports 5 major Southeast Asian and international languages:
1. 🇰🇭 **Khmer (`km`)** — Default locale
2. 🇺🇸 **English (`en`)**
3. 🇨🇳 **Chinese (`zh`)**
4. 🇹🇭 **Thai (`th`)**
5. 🇻🇳 **Vietnamese (`vi`)**

---

## 2. Directory Structure & Namespaces

```text
admin-dashboard/src/locales/
├── km/
│   ├── common.json         # General actions, statuses, buttons
│   ├── products.json       # Product, catalog, tax, attribute terms
│   ├── inventory.json      # Warehouse, stock, movements, transfers
│   ├── pos.json            # Register, tender, discounts, receipts
│   ├── orders.json         # E-commerce, fulfillment, shipping
│   ├── customers.json      # CRM, loyalty tiers, points
│   └── settings.json       # Company, branch, role, user configs
├── en/ (English counterparts)
├── zh/ (Chinese counterparts)
├── th/ (Thai counterparts)
└── vi/ (Vietnamese counterparts)
```

---

## 3. Best Practices for Developers

1. **Never Hardcode English or Khmer in JSX**:
   ```tsx
   // ❌ Bad
   <button>Save Changes</button>
   
   // ✅ Good
   <button>{t('common.save')}</button>
   ```
2. **Dynamic Placeholders with Fallbacks**:
   ```tsx
   // ✅ Good
   <SearchInput placeholder={t('products.searchPlaceholder', 'Search SKU or name...')} />
   ```
3. **No Duplicate Translation Keys**:
   Always verify that top-level and nested keys do not overwrite one another in locale JSON dictionaries.

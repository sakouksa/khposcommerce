## 🎫 CARD 1: Web/Backend - Employee Holiday Management & Spatie RBAC (5)
**Status:** `In Progress` | **Priority:** `P0` | **Points:** `5`

### Goal
Add a dedicated, enterprise-grade Holiday Management system inside the Employee Module so Company Admins can manage public, religious, and company-specific holidays, automate leave/attendance calculations, sync national holidays via live API, and ensure strict RBAC access control.
- Covers: Web Client (`webclient/admin-khposcommerce`), Backend API (`api/backend-khposcommerce`).

### Important Security Rule (Multi-Tenancy)
```
Company A Admin ──► Can view/manage Company A holidays
Company A Admin ──► CANNOT view/modify Company B holidays
```
- Backend routes MUST be protected by Spatie permission middleware (`permission:holiday.view`, `permission:holiday.create`, `permission:holiday.update`, `permission:holiday.delete`).
- Eloquent query automatically scopes by `company_id`.

### Page Layout (HolidaysTab.tsx)
```

[ Search holiday... ]  [ Status: All ▾ ]  [ Year: 2026 ▾ ]   [ Sync Live API ]  [+ Add Holiday]

[x] | Holiday Title (EN/KM)       | Date         | Day     | Recurring | Status   | Actions
-----------------------------------------------------------------------------------------
[ ] | Khmer New Year (បុណ្យចូលឆ្នាំ) | 14-16 Apr 2026 | Tue-Thu | [ Yes ]   | [Active] | [ ⋮ ]
[ ] | International Labor Day     | 01 May 2026  | Friday  | [ Yes ]   | [Active] | [ ⋮ ]
-----------------------------------------------------------------------------------------
```

### Backend API & FormRequests
- `GET /api/v1/admin/holidays` -> `permission:holiday.view`
- `POST /api/v1/admin/holidays` -> `permission:holiday.create` (StoreHolidayRequest)
- `PUT /api/v1/admin/holidays/{id}` -> `permission:holiday.update` (UpdateHolidayRequest)
- `DELETE /api/v1/admin/holidays/{id}` -> `permission:holiday.delete`
- `POST /api/v1/admin/holidays/bulk-delete` -> `permission:holiday.delete`
- `POST /api/v1/admin/holidays/sync-live-api` -> `permission:holiday.create`
